Localize, gate, and curate under a 150-line horizon

Open toolkit for coding-agent research: rank ≤150-line read windows with AST-HorizonGraph, enforce two-sided soundness, select serve-cost-aware trajectories with MS-SFT, and probe construct validity on SWE-HorizonBench-OOD.

What it does

Four diagnostics in one pip-installable package

AST-HorizonGraph

Parse a Python repo into import, call, sibling, and attribute edges; weight issue tokens with sub-token IDF; return K disjoint ≤150-line windows — the read budget many agent harnesses enforce.

Two-sided soundness

A task is usable only if empty-patch tests fail and the human oracle patch makes them pass. Also classifies topology S1 / S2 / S3 and the >150-line companion-hunk flag.

MS-SFT selector

Score sound passing rollouts by tokens, steps, excess hunks, and scratch contamination. Keep one serve-cost-optimal winner per task so LoRA fine-tuning stays inside a fixed wall-clock budget.

OOD + @kbench.task

A 60-task out-of-distribution probe across 8 external libraries, plus a 3-task native Kaggle Benchmarks suite that runs offline via a deterministic shim or live with kaggle_benchmarks.

Pipeline

From broken tests to serve-aware curation

01 Gate two_sided_sound
02 Localize ASTHorizonGraph
03 Topology classify_topology
04 Curate select_ms_sft
05 Verify kbench-suite

Why a 150-line horizon?

Many coding-agent stacks truncate read_file at 150 lines (or 10k chars). Agents often open the right file yet miss companion edit sites deeper in the same module. HorizonGraph allocates multiple windows under that hard budget.

Construct-validity warning

Synthetic OOD prompts that name Python symbols inflate lexical and graph recall the same way seeded gold-file pools do. Use OOD as a fast CPU sanity check — not as proof of end-to-end unseeded retrieval.

Usage

CLI and Python API

CLI 
python3 -m swe_horizon_bench.cli localize \
  --repo /path/to/repo \
  --query "timeout ignored when follow_redirects=False" \
  --seed src/client.py \
  -k 3
Python 
from swe_horizon_bench import localize_windows

wins = localize_windows(
    "~/code/myrepo",
    "pluggy hook wrapper order",
    seed_file="src/pluggy/_hooks.py",
    k=3,
)
for w in wins:
    print(w["path"], w["start_line"], w["end_line"], w["score"])
Python 
from swe_horizon_bench import two_sided_sound, classify_topology

gate = two_sided_sound(
    empty_pass=False,   # tests must fail without a patch
    oracle_pass=True,   # human fix must make tests pass
    candidate_pass=True,
)
assert gate["usable"]

topo = classify_topology(open("gold.patch").read())
print(topo["topology"], topo["any_file_delta_L_gt_150"])
Python 
from swe_horizon_bench import j_ms, select_ms_sft

score = j_ms(
    sound=True, tokens=3918, steps=24, hunks=2, gold_hunks=3, scratch=False,
    alpha=1.5, beta=1.0, gamma=0.5, delta=2.0,
)

winners = select_ms_sft([
    {"task_id": "t1", "sound": True, "tokens": 3918, "steps": 24,
     "hunks": 2, "gold_hunks": 3, "scratch": False},
    {"task_id": "t1", "sound": True, "tokens": 6200, "steps": 40,
     "hunks": 5, "gold_hunks": 3, "scratch": True},
])
print(winners["t1"]["j_ms"], score)
